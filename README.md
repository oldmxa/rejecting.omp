**Deathmatch gamemode for [open.mp](https://open.mp), developed by oldmxa.**

## Features

**Gameplay**

* Custom arenas & maps
* 1v1 & 2v2 duels
* Training & practice modes
* Tournaments

**Clans**

* Clan management
* Dynamic clan colors & tags
* Outpost territory system
* Safehouses

**Interface**

* Modular TextDraw system
* Custom HUDs
* Skin & vehicle selectors
* In-game menus

**Security**

* Integrated anti-cheat
* NOP detection
* Anti-VPN
* Punishment & administration logs

**Infrastructure**

* MySQL / MariaDB
* Discord integration
* Modular Pawn architecture
